Conflict graph (graph coloring)

Each circle is a class. A line joins two classes that run at the same time, so they must get different rooms. Colour = assigned room; grey dashed = no room.

How the algorithm decided

Classes with the most conflicts are coloured first (Welsh-Powell). Each one then takes the smallest suitable free room (greedy).
